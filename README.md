# DCS-FoxHandler


Dependancies:
ChaosTools
TableIO


This is an accessibility mission script for adding VA for users that have inhibiting or limiting factors for speech. This script and set of audio files aims to allow those users to still call their shots for the rest of the team over TACCOM, to players in their local area, by using eventhandlers to efficiently detect and execute on this information.


This script was made specifically for friends of mine, so they have specialized callsigns in the VA files. You may use un-callsigned vocies if your callsign isnt in there. If you or someone you know uses the script and would like their callsign added, please contact Chaos.
If you would be open to recording some voice acting for additional voices for the script, plase contact Chaos.
